# User Stories

Stories are listed in priority order and grouped by sprint. Each story is in the standard format:
**As a [type of user], I want to [action] so that [benefit].**

---

## Sprint 1

| Story | Status |
|-------|--------|
| As a user, I want to create an account with a unique username so that I can begin using the app. | Done |
| As a user, I want to be able to securely log in to the application with a created account so that I can catalog my health biometrics. | Done |

---

## Sprint 2

| Story | Status |
|-------|--------|
| As a user, I want to be able to select, on account creation, whether I am an individual user or a caregiver so that I can gain access to the features I need. | Done |
| As a user, I would like to be able to link a caregiver account to my patient profile so that they can view and manage my biometric information. | Done |
| As a user, I want to be able to update my profile information as necessary so that it properly reflects accurate information. | Done |
| As a user, I want to receive alerts for concerning readings so that I can seek medical assistance if need be. | Done |
| As a user, I want to be able to upload official records to my profile to help with my assessment and to store and compare long term patterns. | Done |
